# SignSure Mobile Notary – Real Estate Closing Services

A professional, luxury-refined website template for a mobile notary signing agency serving real estate closings.

## 🎨 Design Direction

**Aesthetic:** Luxury-Refined — conveying trust, professionalism, and premium service.

### Design System
| Token | Value |
|-------|-------|
| **Primary** | Deep Navy `#1B2A4A` |
| **Secondary** | Warm Gold `#C8A45E` |
| **Accent** | Teal `#2D8B7A` |
| **Heading Font** | Playfair Display (variable weight) |
| **Body Font** | DM Sans (variable weight) |
| **Border Radius** | 8px globally |
| **Icons** | Remix Icons |

## ✨ Features

- **Dark/Light Mode** — System preference detection + localStorage toggle
- **RTL Support** — Full right-to-left layout with `dir="rtl"` toggle
- **Responsive** — Breakpoints at 1440, 1024, 768, and 360px
- **Accessible** — WCAG 2.1 AA compliant, keyboard nav, focus states
- **SEO Optimized** — Unique titles, meta descriptions, JSON-LD, semantic HTML
- **Form Validation** — Client-side validation on all forms
- **Dashboard** — Full title company client portal with:
  - Signing appointment scheduling & tracking
  - Document uploads & downloads
  - Invoice management
  - User management
  - Messages & notifications
  - Reports & analytics
  - Settings

## 🚀 Usage

No build tools required. Open `index.html` in any modern browser.

### CDN Dependencies
- [Remix Icons](https://remixicon.com/) — Icon library
- [Google Fonts](https://fonts.google.com/) — Playfair Display, DM Sans

## 📱 Responsive Breakpoints

| Breakpoint | Behavior |
|------------|----------|
| > 1440px | Large desktop |
| 1025–1439px | Standard desktop, full navbar |
| ≤ 1024px | Tablet — hamburger menu |
| ≤ 768px | Mobile layout |
| ≤ 360px | Small mobile, full-width drawer |
